# 生图提示词改写

我有一条生图提示词被平台判定违规，导致图片生成失败。请改写这条提示词，规避违规表述。

## 原提示词

> <%- prompt %>

## 改写要求

1. 画面主体、场景、构图不变；风格（漫画/绘本/手绘插画质感）、色彩基调、比例、画幅文字内容不变。
2. 替换或删除可能触发平台风控的表述（如敏感人物、敏感事件、极限词汇、易误判的字面组合等），改用中性、描述性的语言传达同样的画面。
3. 保留原提示词末尾的禁止项要求（如"禁止出现水印、二维码、平台标识、乱码与额外文字"）。

以 json 代码块回复，schema 如下（未列字段一律不写）：

```jsonc
{
  "prompt": "", // 改写后的完整提示词文本（单行纯文本，不含引号转义外的任何格式包裹）
}
```

只回复一个 JSON 代码块，JSON 之外最多加一句"已改写完成"。
