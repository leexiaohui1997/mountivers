# 图片质量校验

我发送的这张图片由 AI 按下面的生图提示词生成，请对它做质量校验。

## 生图提示词

> <%- prompt %>

## 校验维度（对照提示词逐项检查）

1. **提示词符合度**：构图、风格、色彩是否符合生图提示词要求；画面主体与场景是否与提示词描述对应。
2. **画面文字**：是否有多余文字、乱码；要求出现的画面文字（大字/小字）是否清晰、内容正确、无错别字。
3. **水印与标识**：是否残留水印、二维码、平台标识（注意：经去水印处理的图片仍需复核水印是否清干净）。
4. **风格统一**：是否保持合集统一视觉基调——漫画/绘本/手绘插画质感（非写实摄影）、低饱和暖色调、大面积留白、情绪克制有故事感；封面与合集封面风格是否一致。
5. **画面质量**：主体是否完整无裁切缺失；有无明显畸变、肢体错误、元素崩坏。

## 输出要求

只依据画面实际内容判断，不臆测。`checks` 必须逐一列出上方 5 个校验维度，一项不落；每项判定从严：不达标即 `pass: false` 并在 `reason` 中明确指出具体问题，问题描述要具体可执行（如"画面文字：小字第三个字为乱码"），不写"效果一般"这类模糊表述。整体 `pass` 为所有检查项全部通过。

若存在不通过项，`suggestion` 必须直接给出**调整后的完整生图提示词**：该字段会被原样用于重新出图，因此必须是可直接生图的最终提示词（完整、单段、保留原有的比例/画幅与画面文字要求，并修复所有不通过项）；不要写“建议”“可以”“调整方向”之类的说明性文字，也不要在前面加“调整后提示词示例：”等标签。若整体合格，`suggestion` 留空字符串。

以 json 代码块回复，schema 如下（未列字段一律不写）：

```jsonc
{
  "pass": true, // 整体是否合格：所有检查项全部通过才为 true
  "checks": [
    {
      "name": "提示词符合度", // 校验维度名，与上方 5 个维度一一对应
      "pass": true, // 该检查项是否通过
      "reason": "", // 不通过的具体原因；通过则留空字符串
    },
    // ...其余维度同理，共 5 项
  ],
  "suggestion": "", // 调整后的完整生图提示词，可直接用于重新出图（整体合格则留空）
}
```

只回复一个 JSON 代码块，JSON 之外最多加一句"已生成 check.json"。
