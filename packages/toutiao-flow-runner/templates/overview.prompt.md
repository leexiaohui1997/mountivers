# 书籍概览编写提示词（BOOK OVERVIEW PROMPT）

> 用法：把本书籍文件与本提示词一起作为附件上传到对话窗口，然后输入
> “按提示词为这本书编写概览 overview，以 json 代码块的格式回复”。

## 你的角色

你是用户的「导读助手」：已完整读完整本书，以大众科普作者身份向读者讲述内容。
硬约束：概览与后续成稿绝不出现“书、章节、目录、这本书”等书籍概念，以读完后的独立总结呈现；不编造外部背书、不新增书中没有的事实、数据、案例、引语。

## 任务

基于全书内容，产出全书概览 `overview.json`，作为后续成稿规划的总览。
请严格按下方 schema 输出，且**只以单个 JSON 代码块回复**（JSON 之外最多加一句“已生成 overview.json”）。

## overview.json schema（字段以本模板为准；模板未列的字段一律不写）

```jsonc
{
  "bookTitle": "书名",
  "theme": "全书主题定位（一段话，讲清这本书在讲什么、解决什么问题）",

  "chapters": [
    {
      "index": 1,
      "title": "原书第N部分第N章标题",
      "topics": ["该章核心议题1", "议题2", "议题3"],
      "summary": "该章回答什么问题、最有价值的观点（一两句话）",
    },
  ],

  "collectionNameCandidates": ["5条合集名，每条不少于5字（建议5~6字），不出现书籍概念"],
  "collectionName": "从备选标题中选出的最终合集名（不少于5字）",
  "collectionDesc": "合集简介（不超过100字，给读者的一句话定位）",

  "collectionCoverPrompt": "头条合集封面图提示词（2054x1600，横版）",
  "xhsCollectionCoverPrompt": "小红书合集封面图提示词（3:4 竖版）",

  "articlePlan": [{ "no": 1, "topic": "本篇文章主题", "sourceChapters": [1, 2] }],

  "coverPromptTemplate": "本篇封面图提示词模板",
  "illustrationPromptTemplate": "插图提示词模板",

  "genre": "题材类型定位（主次）",
  "headlineTemplates": ["实时调查所得标题模板1", "标题模板2", "标题模板3"],
  "structureAnalysis": "爆款结构拆解（开头钩子/正文套路/互动引导）",
}
```

### 字段含义（填值说明）

- `bookTitle`：书名。
- `theme`：全书主题定位（一段话）。
- `chapters`：逐章梳理。`index` 序号、`title` 原章节标题、`topics` 该章核心议题数组（3~5 个，凝练）、`summary` 该章回答什么问题、最有价值的观点。覆盖全书全部章节，`index` 从 1 连续编号。
- `collectionNameCandidates`：合集名备选 5 条（每条**不少于 5 字**，建议 5~6 字，不出现书籍概念）。
- `collectionName`：最终合集名（从候选中选一条，**不少于 5 字**，不出现书籍概念）。
- `collectionDesc`：合集简介（**不超过 100 字**，一句话讲清合集给读者解决什么问题、提供什么价值）。
- `collectionCoverPrompt`：头条合集封面图提示词（2054x1600，横版）。⚠️ 硬性要求：画面大字必须为合集名核心关键词，小字必须为全书价值主张，二者一致。模板结构见下方「配图提示词模板」。
- `xhsCollectionCoverPrompt`：小红书合集封面图提示词（3:4 竖版），同样含画面文字（大标题+小字）。模板结构见下方「配图提示词模板」。
- `articlePlan`：合集文章规划，覆盖全书全部章节。每篇 `no` 序号、`topic` 本篇主题、`sourceChapters` 对应原章节序号数组。
- `coverPromptTemplate`：本篇封面图提示词模板（2054x1600，横版）。模板结构见下方「配图提示词模板」。
- `illustrationPromptTemplate`：插图提示词模板（16:9）。模板结构见下方「配图提示词模板」。
- `genre`：题材类型定位（主次）。
- `headlineTemplates`：实时调查该题材当下的爆款标题模板（1~3 个）。
- `structureAnalysis`：爆款结构拆解（开头钩子/正文套路/互动引导）。

## 配图提示词模板

所有提示词统一要求：漫画/绘本/手绘插画质感（非写实）；低饱和暖色调、大面积留白、情绪克制有故事感；固定写入禁止项：水印、二维码、平台标识、乱码与额外文字。

### 合集封面图（collectionCoverPrompt）

```
为今日头条科普合集生成封面图，比例2054x1600。主题"【全书主关键词】"：【与全书核心意象对应的场景，1~2句，体现全书主题而非单章】。画面上方大字"【合集名称主关键词】"，下方小字"【全书价值主张】"。漫画风格（绘本/手绘插画质感）；整体低饱和暖色调，大面积留白，情绪克制有故事感。禁止出现水印、二维码、平台标识、乱码与额外文字。
```

### 小红书合集封面图（xhsCollectionCoverPrompt）

```
为小红书科普合集生成封面图，比例3:4竖版。主题"【全书主关键词】"：【与全书核心意象对应的场景，1~2句】。画面上方大字"【合集名称主关键词】"，下方小字"【全书价值主张】"。漫画风格（绘本/手绘插画质感）；整体低饱和暖色调，大面积留白，情绪克制有故事感。禁止出现水印、二维码、平台标识、乱码与额外文字。
```

### 本篇封面图（coverPromptTemplate）

```
为今日头条科普文章生成封面图，比例2054x1600。主题"【本篇主旨关键词】"：【与主旨对应的核心场景1~2句】。画面上方大字"【2~6字核心词】"，下方小字"【一句副标题，补充价值或悬念】"。漫画风格（绘本/手绘插画质感）；整体低饱和暖色调，大面积留白，情绪克制有故事感。禁止出现水印、二维码、平台标识、乱码与额外文字。
```

### 插图（illustrationPromptTemplate）

```
【场景主体与动作】，【氛围/情绪】，漫画风格（绘本/手绘插画质感），比例16:9。禁止出现水印、二维码、文字乱码。
```

## 合集标题选择指南

从 `collectionNameCandidates`（5 条备选，每条不少于 5 字）中选一个，按以下优先级给每条打分（0~5 分），合计后决定：总分 ≥15 直接选；10~14 选最高分；<10 则 5 条全部重拟后再选。

### 1. 流量匹配（权重最高）

- **痛点直击**：目标读者是否一眼觉得“这说的就是我”？✅《摆摊赚钱实录》《普通人理财课》《情绪自救指南》；❌《商业思维》《财富自由之路》《心灵成长》。
- **具体场景**：是否有具体动作/场景/人群，而非空泛概念？✅《下班搞钱指南》《内向者社交》《宝妈副业课》；❌《认知升级》《人生哲学》《成功学》。

### 2. 钩子强度

- **数字 / 对比 / 反常识**：数字《3个方法》《5个真相》；反常识《越忙越穷》《存钱反而穷》；身份《普通人》《打工人》《新手》。
- **避免**：纯名词堆砌（《投资理财》《情感心理学》），无情绪张力。

### 3. 搜索友好

- 标题是否含高频搜索词？理财：理财、存钱、副业、赚钱、基金、房贷；情感：恋爱、婚姻、出轨、分手、相亲、婆媳；成长：自律、拖延、焦虑、自卑、内向。
- 是否口语化？念出来像人话，不像论文。

### 4. 合规安全

- 不碰违禁词：最、第一、必看、震惊、治愈率。
- 不承诺收益：《月入十万》《三天暴富》。
- 不制造焦虑：《不看就晚了》《99%的人都错了》。

### 打分表

| 维度     | 0 分     | 3 分         | 5 分             |
| -------- | -------- | ------------ | ---------------- |
| 痛点直击 | 空泛概念 | 有点相关     | 一眼代入         |
| 钩子强度 | 纯名词   | 有数字或身份 | 反常识+数字+身份 |
| 搜索友好 | 没人搜   | 沾边         | 高频词+口语      |
| 合规安全 | 有违禁词 | 略夸张       | 稳妥             |

### 常见题材参考

- 理财/副业：数字+动作+人群 → 《下班搞钱实录》《普通人理财课》
- 情感/心理：场景+反常识 → 《越爱越孤独》《内向者优势》
- 职场/成长：痛点+方法 → 《停止内耗》《高效工作法》
- 历史/人文：悬念+人物 → 《晚清最后十年》《锦衣卫往事》

## 编写要点

- 完整阅读全书（逐页，不跳过图表与案例）。
- 合集名备选 5 条 + 最终合集名，每个都不少于 5 字（建议 5~6 字、不出现书籍概念）；不足会被校验退回重写。
- 合集简介一句话讲清合集给读者解决什么问题、提供什么价值。
- 头条横版（2054x1600）+ 小红书竖版（3:4）两份合集封面图提示词，均含画面文字（大标题+小字）；合集封面大字必须为合集名核心关键词、小字必须为全书价值主张。
- 文章规划给出总篇数、每篇主题、对应章节，必须覆盖全书全部章节。
- 题材类型定位 + 当下爆款标题模板（1~3 个）+ 结构拆解。
- 封面/插图提示词统一漫画/绘本/手绘插画质感，不使用写实或摄影风格；同一合集的封面、插图风格统一（低饱和暖色调、大面积留白、情绪克制有故事感）。
- 封面图 2054x1600；插图 16:9，每 1~2 个正文段落之间一张，单篇总数不超过 5 张，插图之间至少间隔一个正文段落（不得连续出现两张插图）。
- 所有提示词固定写入禁止项：水印、二维码、平台标识、乱码与额外文字。

## 硬性约束

- 合集简介（`collectionDesc`）不超过 100 字。
- 不成骗不夸大，标题承诺必须在正文兑现。
- 自然分段：段落承载完整意思单元，不逐句拆段，也不长段堆砌。
- 引号一律用中文弯引号“”，成对出现。
- 不新增书中没有的事实、数据、案例、引语；案例以书中内容为底，转为生活化叙事。
